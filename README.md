# React Chatbot 🤖

A functional, interactive chatbot web application built with React. 

**Live Demo:** [Chatbot on Vercel](https://chatbot-hazel-rho-31.vercel.app/)

## ✨ Features

* **Message Persistence:** Chat history is automatically saved using `localStorage`, ensuring conversations aren't lost when the page is refreshed.
* **Smart Auto-Scrolling:** The chat interface automatically snaps to the most recent messages for a seamless user experience.
* **Simulated Loading States:** Includes realistic typing and loading indicators to make the bot interaction feel more natural and responsive.

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript, HTML, CSS
* **Deployment:** Vercel
